## الإعداد والاستخدام

يتضمن المستودع نسختين مستقلتين من المصدر ولكل منهما `main`. ابنِ نسخة واحدة في كل مرة، مثلاً من Visual Studio Developer Command Prompt:

```bat
cl /EHsc /std:c++17 main.cpp /Fe:bank.exe
bank.exe
```

يقرأ المصدر `Clients.txt` و`Users.txt` من مجلد التشغيل. استخدم بيانات وهمية توافق تنسيق النسخة المختارة. لا تربط الملفين في برنامج تنفيذي واحد.

يستخدم كود الطرفية أوامر Windows مثل `cls` أو `pause`، لذا Windows هو البيئة المقصودة. توضح الأوامر أدناه نقطة بناء المصدر، ولم تجر ترجمتها ضمن تحديث التوثيق.
